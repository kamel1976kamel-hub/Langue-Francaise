🔍 Dépannage

Problèmes courants et solutions:
  • "undefined rules" → Utilisez les fichiers -simple.js pour éviter les erreurs de syntaxe
  • "NaN confidence" → Le pipeline avancé calcule automatiquement une confiance valide
  • "Groq API error" → Vérifiez votre clé API et la connexion internet
  • "Too many corrections" → Le système limite automatiquement à 20 corrections maximum
✅ Points de vérification:
  • Les scripts sont chargés dans le bon ordre
  • La clé API Groq est configurée
  • Les fichiers -simple.js sont utilisés (pas les fichiers défectueux)
  • La console montre "Pipeline avancé initialisé"
