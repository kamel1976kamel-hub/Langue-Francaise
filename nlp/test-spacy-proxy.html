🌐 spaCy Cloud via Proxy

Solution CORS pour utiliser spaCy professionnel depuis le navigateur

🚀 Instructions pour démarrer

  1. Ouvrir un terminal dans le dossier nlp/python-server/
  2. Démarrer le proxy spaCy :
    & "C:\Users\horizon pc\AppData\Local\Programs\Python\Python311\python.exe" proxy-server.py
  3. Attendre le message : "Running on http://localhost:8001"
  4. Garder le terminal ouvert (ne fermez pas !)
  5. Actualiser cette page et tester !

⚠️ Note : Le proxy utilise Hugging Face API (nécessite connexion internet)
